# Micro-Event Backend API

A backend API for a location-based event management platform that allows users to create, discover, attend and manage local events happening nearby around their location.

## Features

- User authentication
- Event creation and updates
- Nearby event search
- Attendance management
- Event comments and replies
- Push notifications
- Scheduled event reminders
- Admin event moderation

## Tech Stack

- Node.js
- Express.js
- TypeScript
- MongoDB
- Firebase Cloud Messaging
- Cloudinary
- Node-cron
